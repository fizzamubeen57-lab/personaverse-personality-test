# PersonaVerse 🧠

PersonaVerse is an interactive personality test web application designed to help users explore different aspects of their personality through engaging tests, quizzes, and interactive features.

## 🌐 Live Demo

https://personality-test-web.netlify.app

## ✨ Features

- 🧠 Personality tests
- 📊 Interactive personality results
- 🔹 MBTI personality test
- 🔹 Big Five personality test
- 🔹 DISC personality test
- 🔹 Enneagram personality test
- ❤️ Personality compatibility
- 🎮 Interactive personality games
- 📝 Personality-related blog section
- 🏆 Leaderboard
- ♈ Zodiac section
- ⚙️ Settings page
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Pages

- Home
- Personality Tests
- MBTI
- Compatibility
- Games
- Blog
- Leaderboard
- Settings
- Zodiac

## 🎯 Purpose

The purpose of PersonaVerse is to provide an engaging and easy-to-use platform where users can explore personality types, take different personality tests, and learn more about themselves.
